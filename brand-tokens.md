## Typography
- **Family: STK Bureau** (serif + sans, same family). Licensed — https://typekiosk.smuss.studio/
- **STK Bureau Serif** — Light. Editorial, credibility. Use for headlines/big numbers.
- **STK Bureau Sans** — Light / Book / Medium. Clean, readable. Use for body/labels.
- **Not free.** For the deck without the license, closest free fallbacks: serif → *Newsreader* or *Spectral* (Light); sans → *Inter* or *Arial/Helvetica* (neo-grotesque match).

## Usage rules (that affect the deck)
- **Text over any color spectrum = Charcoal `#212121` only.** Lighter text tested as illegible/inaccessible.
- Don'ts: White-on-Cream, Cream-on-White, Cream on color spectrum, color-spectrum text on any spectrum/Cream/White/Charcoal.
- Logo: wordmark-based (e.g. `9am_Wordmark_RGB_Black.svg`), "riffable/dynamic" not locked-up.

## Practical deck palette (safe defaults)
- Background: Cream `#FFFCF3`
- Text: Charcoal `#212121`
- Accent / chart primary: Sunrise blue `#80AEFF`
- Chart secondary/tertiary: `#F7BDE6`, `#FFBD70`, `#B0F2CE`, `#ABD4FF`
